# Privacy

Cuota runs entirely on your computer, inside Claude Code. Chechesa Labs does not receive any data from it.

- **What it reads:** the usage percentages and reset times that Claude Code reports for your plan, the folder you are working in, and the `language` setting of Claude Code.
- **What it stores:** the caps you set for each folder and the latest usage reading, in the plugin's own local storage on your computer. They stay there until you remove them (`/cuota default`) or uninstall the plugin.
- **What it sends:** nothing, unless you set the optional `webhook` setting. Then it sends usage events to the address you entered, and only there. The README section "What it reads, sends and changes" lists every field.
- **No accounts, no analytics, no tracking.** It does not read your files or your messages, and it does not call the model.

Questions: open an issue at https://github.com/chechesa-labs/claude-code-cuota/issues
